# PawsRescue Web Application

## Project Description
PawsRescue is a responsive web application designed to connect pet adopters with shelters and rescue organizations. Built as part of the DLBCSPJWD01 course at IU International University of Applied Sciences.

## Tech Stack
* **Front-End:** HTML5, CSS3, JavaScript (Responsive Layout)
* **Back-End:** Node.js / Express
* **Database / API:** MySQL Database & Custom REST APIs
